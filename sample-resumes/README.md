# Sample Resumes

This folder is for testing the Smart Resume Analyzer with sample resume PDFs.

## How to Add Sample Resumes

1. Place your resume PDF files in this folder
2. Use them to test the upload and analysis features

## Recommended Sample Resumes

For comprehensive testing, add resumes for different job roles:
- **Data Scientist** - Should include Python, Machine Learning, SQL, statistics skills
- **Frontend Developer** - Should include JavaScript, React, CSS, HTML skills
- **Backend Developer** - Should include Python/Java/Node.js, APIs, database skills
- **Full Stack Developer** - Should include both frontend and backend skills
- **DevOps Engineer** - Should include Docker, Kubernetes, CI/CD, cloud skills

## Testing Tips

- Test with resumes of different lengths (short, medium, long)
- Test with resumes that have missing sections (no education, no experience, etc.)
- Test with resumes that have different formatting styles
